# All Things Pebble

A community-curated directory of all things related to Pebble smartwatches and and other devices based on PebbleOS.

Something missing? Please add it by making a PR!

## Browse the directory

- [Core Devices](core-devices.md) - The new Pebble watches, apps, developer resources and repos from Core Devices.
- [Rebble Alliance](rebble.md) - The community keeping Pebble alive: web services, app store, developer resources and repos.
- [Development](development.md) - SDKs, build tools, languages, libraries and integrations.
- [Art & Design](art-design.md) - Design tools, fonts, icons and graphics utilities.
- [Hardware](hardware.md) - Smartstraps, 3D prints and other hardware resources.
- [Community](community.md) - Forums, companion apps, translation, education and news.
- [Pebble Watchfaces](watchfaces.md) and [Pebble Apps](watchapps.md) - Directories of open source watchfaces and apps.
- [Pebble Technology Corporation](pebble-technology.md) - The original Pebble company: history, archives, repairs and the original watches.
