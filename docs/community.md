# Community

## Forums & Social

- [r/Pebble](https://www.reddit.com/r/pebble/) - Pebble community sub-reddit.
- [r/PebbleDevelopers](https://www.reddit.com/r/pebbledevelopers/) - Pebble community sub-reddit for developers.
- [Willow Systems Pebble Links](https://willow.systems/pebble/) - Handy list of Pebble resources including hardware, patched apps and SDK links.

## Companion Apps

- [Gadgetbridge](https://gadgetbridge.org/) - Open source Android app for using smartwatches without vendor apps. Supports Pebble ([Pebble notes](https://gadgetbridge.org/internals/specifics/pebble/)).
- [RockWork](https://gitlab.com/muhammad23012009/rockwork) - Pebble companion app for Ubuntu Touch / Linux phones.
- [Pebble with CGM Notes](https://github.com/clach04/not-yet-definitive-pebble-guide/blob/main/pebble_cgm.md) - Notes on using Pebble with continuous glucose monitors for diabetes.


## Localization

- [Crowdin PebbleOS Translation](https://crowdin.com/project/pebbleos) - Help translate PebbleOS into different languages.
- [pebble-firmware-utils](https://github.com/MarSoft/pebble-firmware-utils) - Tools for creating language packs for original Pebble watches. See the [Language Packs wiki](https://github.com/MarSoft/pebble-firmware-utils/wiki/Language-Packs).
