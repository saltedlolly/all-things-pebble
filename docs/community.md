# Community

## Forums & Social

- [r/Pebble](https://www.reddit.com/r/pebble/) - Pebble community sub-reddit.
- [r/PebbleDevelopers](https://www.reddit.com/r/pebbledevelopers/) - Pebble community sub-reddit for developers.
- [Willow Systems Pebble Links](https://willow.systems/pebble/) - Handy list of Pebble resources including hardware, patched apps and SDK links.
- [Not-Yet-Definitive Pebble Guide](https://github.com/clach04/not-yet-definitive-pebble-guide/) - Another community-curated list of Pebble resources and links.

## Companion Apps

- [Gadgetbridge](https://gadgetbridge.org/) - Open source Android app for using smartwatches without vendor apps. Supports Pebble.
- [RockWork](https://gitlab.com/muhammad23012009/rockwork) - Pebble companion app for Ubuntu Touch / Linux phones.


## Localization

- [Crowdin PebbleOS Translation](https://crowdin.com/project/pebbleos) - Help translate PebbleOS into different languages.
- [pebble-firmware-utils](https://github.com/MarSoft/pebble-firmware-utils) - Tools for creating language packs for original Pebble watches. See the [Language Packs wiki](https://github.com/MarSoft/pebble-firmware-utils/wiki/Language-Packs).

## Education

- [Learning C with Pebble (2016 Edition)](https://pebble.gitbooks.io/learning-c-with-pebble/content/) - Original eBook created by Mike Jipping and others.
- [Nivx78 Pebble Tutorials](https://nivz78.wordpress.com/2016/10/24/introduction/) - Pebble tutorials created in 2016 (Incomplete)
- [Learning C with Pebble Source](https://github.com/orvi-tmp/learning-c-with-pebble) - Source for the Learning C with Pebble book. Exercise answers [here](https://github.com/learning-c-with-pebble).
