# Art & Design

Tools and references for designing Pebble watchfaces, apps and icons.


- [pdc_tool CLI](https://github.com/HBehrens/pdc_tool) - A command-line interface for working with Pebble Draw Command (PDC) files by [@HBehrens](https://github.com/HBehrens)
- [pdc_tool web viewer](https://pdc-tool.heikobehrens.com) - Web-based tool for previewing SVG/PDC files by [@HBehrens](https://github.com/HBehrens)
- [Inkscape PDC Preview Plugins](https://github.com/hellcp/inkscape-pdc-exporter) - Inkscape plugins to preview an SVG as it will look on a Pebble watch, as well as exporting as pdc. Created by [@hellcp](https://github.com/hellcp/). Requires pdc_tool.
- [Pebble Color Picker](https://developer.rebble.io/guides/tools-and-resources/color-picker/) - View the color pallette supported by Pebble watches with a color display.
- [Bitmap Gallery](https://github.com/hellcp/bitmap-gallery) - Simple app for previewing images on a Pebble watch.
- [Pebble Renderer](https://pebble-render.aru.dev/) - Render your screenshots onto Classic, Time and Round Pebble watch frames.
- [Pebbleface Studio](https://studio.pebbleface.com/) - Online Pebble watchface generator. Source [here](https://github.com/Yorks0n/pebbleface-studio) and [here](https://github.com/Yorks0n/pebble-face-builder).
- [Pebble Watchface Builder](https://github.com/tapresle/pebble-watchface-builder) - Browser-based drag-and-drop watchface builder for Pebble Time 2, Pebble 2 Duo and Pebble Round 2 that outputs Pebble C SDK code.
- [Pebble Watchface Generator](https://github.com/HarrisonAllen/pebble-watchface-generator) - Tool for generating watchfaces automatically.
- [svg2pdc-rs](https://github.com/FlyinPancake/svg2pdc-rs) - Converts SVG files to Pebble Draw Command (PDC) format, written in Rust.
- [Lopaka](https://lopaka.app/) - Web-based graphics editor for tiny screens.
- [Pebble Aseprite Palettes](https://github.com/lavglaab/pebble-aseprite-palettes) - Pebble color palettes for the Aseprite pixel art editor.
- [Heydays Pebble Archive](https://old.heydays.no/project/pebble/) - The design studio behind the original Pebble UI. A great reference for Pebble's icons and visual style.
