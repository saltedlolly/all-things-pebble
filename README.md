# All Things Pebble

A community-curated directory of all things related to Pebble smartwatches and other devices based on PebbleOS.

**👉 Browse the directory at [allthingspebble.saltedlolly.com](https://allthingspebble.saltedlolly.com/)**

## Sections

- [Core Devices](docs/core-devices.md) - The new Pebble watches, apps, developer resources and repos from Core Devices.
- [Rebble Alliance](docs/rebble.md) - The community keeping Pebble alive: web services, app store, developer resources and repos.
- [Development](docs/development.md) - SDKs, build tools, languages, libraries and integrations.
- [Art & Design](docs/art-design.md) - Design tools, fonts, icons and graphics utilities.
- [Hardware](docs/hardware.md) - Smartstraps, 3D prints and other hardware resources.
- [Community](docs/community.md) - Forums, companion apps, translation, education and news.
- [Pebble Watchfaces](docs/watchfaces.md) and [Pebble Apps](docs/watchapps.md) - Directories of open source watchfaces and apps.
- [Pebble Technology Corporation](docs/pebble-technology.md) - The original Pebble company: history, archives, repairs and the original watches.
